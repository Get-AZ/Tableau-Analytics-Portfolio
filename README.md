# Tableau Analytics Portfolio

Tableau portfolio by Getamesay Zegeye featuring sales-performance analysis and earthquake geospatial analytics. The repository includes portable Tableau workbooks and their supporting Excel data files.

## Projects

### 1. Sales Performance Analysis

This Tableau project examines sales, revenue trends, returned orders, geographic performance, product categories, and salesperson results using Global Superstore data.

Key analytical views include:

- Revenue trends
- Regional and country-level sales
- Sales by product category
- Salesperson performance and units sold
- Returned-order analysis and return rate
- United States sales map
- Country, state, and city hierarchy

Files:

- `projects/sales-performance/Sales_Performance_Analysis.twb`
- `projects/sales-performance/data/GlobalSuperstore.xlsx`

### 2. Earthquake and Geospatial Analysis

This Tableau project analyzes earthquakes of magnitude 6 or greater through maps, magnitude comparisons, depth analysis, and country-level summaries.

Key analytical views include:

- Earthquake locations and magnitudes
- Depth versus magnitude
- Highest-magnitude earthquakes by country
- Countries with the most recorded earthquakes
- Global geospatial distribution

Files:

- `projects/earthquake-geospatial/Earthquake_Geospatial_Analysis.twb`
- `projects/earthquake-geospatial/data/Mag6PlusEarthquakes.xlsx`

## Open the projects

1. Download or clone this repository.
2. Keep each workbook in its project folder with the accompanying `data` folder.
3. Open the `.twb` file using Tableau Desktop or Tableau Public.
4. If Tableau requests a data connection, select the Excel file inside that project's `data` folder.
